Endless climb: the alternating-gap model

Every row is a platform with a single gap, and the gaps alternate ends from row to row. The mouse runs the platform, then climbs the drawn diagonal to the next row up — while the world scrolls beneath it.

1. The rows

Each row's solid platform is x − g long. The gap switches ends every row, so the next row's platform always ends g short of this row's end.

2. The diagonal

d = √(h² + g²)

From the lower platform's end, the ramp reaches the upper platform's edge: it rises h while running g sideways, so the ramp itself is the hypotenuse.

3. The two speeds

Mouse path = (x − g) + d
Mouse time T = ((x − g) + d) / s
Scroll advance in time T = h × T
Scroll row-clock = h / a = 1 second per row (since a = h)

The race the model sets up: the mouse covers its whole row's path — the full platform plus the diagonal — while the world drops h every second.

Variables

x
Full width of a row — one platform's total span.
g
Length of the single gap in a row.
x − g
Solid length of each platform.
h
Vertical distance between successive platforms (rows). This is the H in the diagonal formula.
d
Drawn diagonal from a platform's end to the next platform's edge: √(h² + g²).
s
Mouse speed, along the platform and up the diagonal.
a
Auto-scroll speed, h per second — the world drops one row-spacing every second.
T
Mouse's time for one row's path: ((x − g) + d) / s.

Diagram proportions are illustrative, not to game scale — the labels, not the pixel lengths, carry the model. The scroll arrow points down because the world moves down as the mouse climbs.
